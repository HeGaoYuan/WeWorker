# 定时任务

定时任务让 AI 在你不在的时候自动工作，并通过消息通道推送结果。

## 创建定时任务

点击侧边栏"定时任务"区域的 "+" 按钮，在右侧配置面板中填写任务信息。

## 任务配置

### 任务标题
给任务起一个描述性的名称，方便识别。

### 执行频率
支持四种频率模式：

| 模式 | 说明 | 示例 |
|------|------|------|
| 每隔 N 分钟 | 每隔固定分钟数执行 | 每 30 分钟 |
| 每小时 | 每小时的指定分钟执行 | 每小时第 0 分钟 |
| 每天 | 每天的指定时间执行 | 每天 09:00 |
| 每周 | 每周指定日期和时间执行 | 每周一 09:00 |

配置完成后，界面会显示接下来 3 次的执行时间，方便确认。

### 任务描述
用自然语言描述 AI 需要执行的任务：

```
帮我查看京东这个月的消费记录，整理成表格，重点标注超过 500 元的订单
```

### 通知通道
选择任务完成后的通知方式：
- **企业微信**：需要先在设置中配置企业微信机器人
- **QQ**：需要先在设置中配置 QQ 机器人
- **微信**：需要先在设置中配置微信通道

> 如果没有配置通道，任务仍会执行，结果会显示在桌面端的对话记录中。

## 执行记录

每次任务执行后，会在"执行记录"中留下记录：
- 执行时间
- 执行状态（成功/失败）
- 点击记录可以跳转到对应的对话，查看完整的执行过程

## 定时任务对话

每次定时任务执行时，会创建一个新的对话，标题格式为：

```
[定时] 任务标题 · MM/DD HH:MM
```

这样在侧边栏中可以一眼识别出定时任务产生的对话。

## 启用/禁用任务

在任务配置页面右上角，可以切换任务的启用状态。禁用的任务不会执行，但配置和历史记录会保留。

## 删除任务

点击"删除"按钮可以删除任务。注意：删除任务会同时删除所有执行记录，此操作不可撤销。
