# 适配网站

WeWorker 通过为每个网站编写专属 Adapter 提供操作能力。下列站点包含：

- **原有适配**：以页面操作为主，打开目标站并登录后，用自然语言描述即可
- **WeCLI（API-first）**：依赖浏览器登录态（cookie/token）调用内部接口，一般无需打开目标页 DOM；标有 `WeCLI · API-first` 的站点另附「子能力」与 `webcli call` 命令示例

> 命令行用法与排错说明见 [wecli](/docs/wecli)。在 Chrome 中完成登录后，可直接把「试试说」复制到 WeWorker 对话中使用。

## 跨网站协作

WeWorker 的强大之处在于可以串联多个网站完成复杂任务。例如：

```
第一步：帮我在163邮箱下载这个月收到的联通发票PDF
第二步：如果发票是加密状态，请解密
第三步：帮我把发票上传到范妮思，并一键匹配
第四步：如果匹配后符合要求请帮我提交，不符合请告诉我还差哪些
```

> 所有需要登录的网站，请提前在 Chrome 中完成登录。
