# 适配网站

WeWorker 通过为每个网站编写专属 Adapter 提供操作能力。下列站点包含：

- **Extension Adapter**：通过浏览器扩展在目标页面或扩展后台执行。
- **Toolkit Adapter**：通过同一安装包内的运行时执行，并通过 `webcli call` 复用统一入口。
- **需要登录的网站**：使用浏览器当前登录态；不得把账号、Cookie、Token 写入命令、截图或日志。

> 命令行用法与排错说明见 [WebCLI](/docs/wecli)。在 Chrome 中完成登录后，可直接把「试试说」复制到 WeWorker 对话中使用。

## 跨网站协作

WeWorker 的强大之处在于可以串联多个网站完成复杂任务。例如：

```
第一步：帮我在163邮箱下载这个月收到的联通发票PDF
第二步：如果发票是加密状态，请解密
第三步：帮我读取发票信息，并整理成可核对的表格
第四步：如果缺少发票附件，请告诉我缺少哪些邮件和关键词
```

> 所有需要登录的网站，请提前在 Chrome 中完成登录。
